# Overlay Novi — 10 segundos

Faixa animada para divulgar a sensi de emulador e mobile do Novi durante a live.

![Prévia animada do overlay](novi-overlay-preview.gif)

- [Baixar pacote ZIP](https://raw.githubusercontent.com/novichupabola-jpg/landingpage97/novi-overlay-downloads/downloads/overlay-novi/novi-overlay.zip)
- [Ver animação no navegador](https://raw.githubusercontent.com/novichupabola-jpg/landingpage97/novi-overlay-downloads/downloads/overlay-novi/novi-overlay-preview.gif)
- [Baixar WebM transparente para OBS](https://raw.githubusercontent.com/novichupabola-jpg/landingpage97/novi-overlay-downloads/downloads/overlay-novi/novi-overlay-transparente.webm)
- [Baixar prévia MP4](https://raw.githubusercontent.com/novichupabola-jpg/landingpage97/novi-overlay-downloads/downloads/overlay-novi/novi-overlay-preview.mp4)

1200 × 400 pixels · 30 fps · 10 segundos · sem áudio.

No OBS, adicione o WebM como Fonte de mídia. Marque Repetir para exibir em loop.
O MP4 e o GIF têm fundo cinza e servem apenas para prévia.

Mensagens: **SENSI DO NOVI → EMULADOR + MOBILE → LINK NA BIO**.
